## 3. Data model changes (all applied before data existed)

- **A.9:** `records.source` accepts `youtube, stackexchange, hackernews, x, quora`.
- **A.10:** `records.collect_method` NOT NULL, one of `official_api | public_feed | public_scraper_lib | headless_render | apify`.
- **A.11:** `records.posts_json`. A thread is ONE record; `posts_json` lists each post's `author_key` and `start`/`end` offsets into `text_clean` (post separator `"\n\n"`). **P2 must use this for per-story authorship:** a story's author is the author of the post its span starts in. NULL for single-post records. It was added with `ALTER TABLE` (nullable, last column), so the file matches a fresh build.
- **New tables:** `analysis_funnel` (step, step_order, source incl. `_all`, n, denom, n_authors, run_id) and `analysis_sources` (per source: method, records, authors, threads, dated, kept, collect_usd, run_id). Both are rebuilt whole by `python -m pipeline.analyse.funnel`.
- `test_committed_corpus_db_matches_schema` now also fails if the committed file's CHECKs are stale.

## 4. The pipeline, in run order

```
python -m pipeline.collect.<module> …        # nine collectors (§2); each run stores a Tally in runs.params_json
python -m pipeline.clean.run_clean           # language (never a drop) → too_short (<20 letters/digits) → dedupe
python -m pipeline.clean.prefilter           # lexicon gate; REPLACES its own earlier marks
python -m pipeline.analyse.funnel            # analysis_funnel + analysis_sources
python -m pipeline.validate.lexicon_probe --n 200   # P1-MET-3, gpt-5-mini, ~$0.045
```

Key properties:
- **PII is scrubbed inside `collect.base.make_record`**, before the first write (`clean/scrub.py`): URLs, emails, `@handle`/`u/handle`, PAN, Aadhaar, card numbers and phones (10–15 digits), all replaced with typed placeholders. Ordinary years and counts are untouched.
- **The `Tally` identity** (P1-INV-1), per collect run: `fetched == written_new + already_present + all_deleted + duplicate_in_batch`.
- **Dedupe** (`clean/dedupe.py`):
  - near-duplicates only within `(source, author_key)`, word-set Jaccard > 0.85;
  - exact duplicates across different authors only when the text is ≥ 25 words (**D-3: two people writing the same short line is consensus**);
  - cross-author echo pairs are counted and reported (276), never removed.
- **The prefilter** (`clean/prefilter.py`, round 2) passes any record containing a lexicon term, a strong retrieval phrase ("can't find", "scrolled through", "search karu", …) or any photo-like word (Latin or Devanagari).
- **`language.py`** tags `en / hi / hi-Latn / mixed / other / unknown`. `text_en` is still NULL everywhere; translation is optional and is an aid only.

**Repair runs in `runs`:**
- `repair-x-truncation`: 18 X records re-mapped from `data/raw`.
- `repair-permalink-pii`: 205 X/Quora URLs rewritten.

Both follow the rule: fix the mapper, then re-map from raw rather than re-buy.

## 8. Gotchas learned this session

1. **An Apify run can say SUCCEEDED and have refused the work.** Always check for `noResults` placeholders; `log_says_limited()` reads the run log.
2. **Interrupting a collector:** `pgrep -f` also matches the zsh wrapper. Kill the Python pid, and **abort the in-flight Apify run** (`POST /actor-runs/<id>/abort`), or it keeps billing.
3. **Auto mode blocks deleting files**, even an empty database. Prefer `ALTER TABLE` for nullable columns; hand the PM a `!` command for rebuilds.
4. `DELETE FROM exclusions WHERE stage='prefilter'` was allowed. The prefilter replaces its own marks by design.
5. Foreground `sleep N; cmd` is blocked in this harness. Use `until …; do sleep; done` loops, or `run_in_background`.
6. **Streamlit Cloud iframe checks:** mouse scrolling does not reach inside the iframe, so use `scrollIntoView` via `iframe.contentDocument`. A long in-page JS poll froze the tab (the CDP 45 s timeout), so poll from the shell instead. "Your app is in the oven" means a rebuild is in progress.
7. **Streamlit Cloud does not restart on a YAML-only push**, so anything cached per process goes stale. Bump `rebuild-token`.
8. Myntra's per-record cost figures counted comments as records. Ours are whole threads, so compare per thread.
